## 🛠️ Course Structure

### 🧮 NumPy Part 1: Foundational Concepts
*File: `numpy_tutorial.ipynb`*
This part introduces you to the core powerhouse of numeric computing—the N-dimensional array (`ndarray`).
*   **Core Mechanics:** Understanding structural axis layout shapes, dimensions, and standard attributes.
*   **Memory Optimization:** Deep dive into explicit memory down-casting using explicit `dtypes`.
*   **The Power of Vectorization:** Eliminating slow Python loops with high-performance vectorized operations.
*   **Slicing & Filtering:** Advanced coordinate extraction and logical boolean masking.

### ⚡ NumPy Part 2: Advanced Mastery & Data Handling
*File: `numpy_tutorial_part2.ipynb`*
Bridge the gap between basic concepts and intermediate mathematical engineering pipelines.
*   **Array Assembly:** Combining or partitioning datasets using `np.vstack`, `np.hstack`, and `np.split`.
*   **Linear Algebra Engine:** Mastering matrix transformations and correct dot products (`np.dot` / `@`).
*   **Predictable Randomness:** Setting up replicable simulation datasets via modern random engines (`default_rng`).
*   **High-Speed I/O Cache:** Saving and reloading large matrices instantly to disk using compressed binary `.npy` storage.

### 🐼 Pandas Series
*File: `pandas_masterclass.ipynb`*
Once you master matrices, we will transition into structural tabular data workflows. This segment will cover:
*   Series and DataFrames structural manipulation.
*   Handling missing dataset rows (NaNs) cleanly.
*   Advanced grouping mechanics (`.groupby()`) and descriptive aggregations.
*   Merging, joining, and parsing real-world `.csv` and `.json` data assets.
